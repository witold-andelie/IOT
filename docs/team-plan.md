# 团队分工与视频拍摄计划

**项目：** Smart Classroom Ventilation（ETEW5E Internet of Things，ČZU，ZS 2026/27）
**成员：** Wentao Ma · Lijie Luo · Jingyi Liu · Zongyuan Chi

> 课程要求：视频里**每个人都要出镜，并讲解一部分内容**。
> 所以视频的做法是：已经做好的动画幻灯片当背景，每个人录一段自己讲解的视频，
> 以画中画的方式放进去（说话的人在画面一角，幻灯片在背后），用真人声音代替原来的 AI 配音。

---

## 1. 先花 30 分钟了解项目（每个人都要做）

1. 看根目录的 [README](../README.md) 第 1 节 "How it works"，搞清楚数据怎么从传感器走到 dashboard。
2. 按 README 第 3 节在自己电脑上把系统跑起来（需要 Docker Desktop），打开 http://localhost:3000 看 dashboard。
   跑不起来就看 README 第 8 节 Troubleshooting，或者在群里问。
3. 读 [技术文档](technical-documentation.md)，**重点读和自己讲解部分对应的章节**（见下表）。
4. 看一遍 AI 配音版的视频草稿（Wentao 会发到群里），了解每个场景大概讲什么、画面是什么。

- 结尾（≈ 10 秒）：一句话总结 "Fresh air, made visible." + 致谢。

**需要理解的内容：** 技术文档第 1、2 节；README 第 1 节（不需要懂技术细节，能用一句话说清"系统做什么"就够了）。

之后也可以在 `video/script.md` 里修改自己那几段台词。

## 5. 拍摄规范（Lijie 会在 `docs/video-production.md` 里细化）

- **设备：** 手机后置摄像头即可，**横屏** 1920×1080、30 fps。手机固定好（支架或书本垫高），镜头与眼睛平齐。
- **构图：** 人在画面中间，头顶上方留一点空间，拍到胸口以上。背景整洁、单色最好，不要逆光（窗户别在身后）。
- **声音：** 安静的房间，关掉空调和风扇；手机离嘴 50–80 cm，有耳机麦克风更好。
  正式录之前先录 10 秒试听。
- **说话：** 英文，语速放慢，看镜头。每段开头和结尾各**停 2 秒**再开口或停止录制，方便剪辑。
- **分段：** 每个场景单独录一个文件，不要一口气录完。说错了就停顿一下，从这句话的开头重新说。
- **文件命名：** `<场景编号>-<名字>.mp4`，例如 `02-motivation-lijie.mp4`、`00-intro-jingyi.mp4`。
- **交付：** 上传到共享网盘（OneDrive / Google Drive），**不要提交到 GitHub**（文件太大）。

## 6. 视频怎么合成（Wentao 负责）

1. 大家的录像放进 `video/public/recordings/`（这个文件夹不进 Git）。
2. Remotion 把每段录像以画中画的方式放在对应场景的幻灯片上，用录像里的声音代替 AI 配音；
   每个场景的长度改为跟随录像时长。
3. 可选：用 Whisper 根据录音自动生成英文字幕。
4. 渲染出 MP4，全组看片，修改，最终上传 Moodle。

提交 PR 的方法见 [CONTRIBUTING.md](../CONTRIBUTING.md)。
